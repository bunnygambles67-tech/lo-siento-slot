# Game Spec v0.1

## Core
5x6 grid, 28 paylines, high/very-high volatility, 50,000x hard cap.

## Bonus hierarchy
3 Hen = Regular (8 spins)
4 Hen = Super (12 spins)
5 Hen = Epic (16 spins)

## Prize tiers
Bronze 1/2/3/5x
Silver 5/10/15x
Gold 25/50/100x
Sapphire 150/200/250/500x
Ruby 750/1000/2500/5000x
Diamond 10000/25000/50000x

## Special systems
Lo Siento Eye, Mystery, Mega Bucket, Double Bucket, Prize Upgrader,
SORRY multiplier, Flood Key, Flood/Redrop, Golden Hen, and Epic
THE HEN FLOATS AWAY.

Bonus Buy and Hunt prices must be derived from the completed feature EV,
not guessed.
